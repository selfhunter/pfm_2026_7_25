# PFM 自适应优化：变形触发局部重分布 + 涡量引导密度调整

## 算法公式与流程图

---

## 一、核心问题

原版 PFM（Particle Flow Maps）采用**固定间隔全局重分布**：

| 层级 | 参数 | 机制 |
|------|------|------|
| 长距离映射 `T_init` | 每 20 步 | 全局重置所有粒子位置、冲量、流图 |
| 短距离映射 `T_grad_m` | 每 8 步 | 全局重置梯度映射 |

**缺陷**：
- 间隔过短 → 频繁破坏流场连续性，增加计算开销
- 间隔过长 → 粒子过度变形，T 张量插值误差增大
- 一刀切 → 涡旋核心与平稳区域同等对待

## 二、创新一：粒子变形因子

### 2.1 定义

```
粒子变形因子 d_i = ||T_i - I||_F

其中：
  T_i = [T_x | T_y] = ┌ T_x.x  T_y.x ┐   (2×2 后向流图雅可比矩阵)
                       └ T_x.y  T_y.y ┘

  I = ┌ 1  0 ┐   (单位阵，代表无变形)
      └ 0  1 ┘

  ||A||_F = sqrt(Σ A_ij²)   (Frobenius 范数)
```

### 2.2 展开计算

```
||T - I||_F² = (T_x.x - 1)² + (T_x.y - 0)² + (T_y.x - 0)² + (T_y.y - 1)²

d_i = sqrt[(T_x.x - 1)² + T_x.y² + T_y.x² + (T_y.y - 1)²]
```

每个粒子只需 4 次减法、4 次平方、3 次加法、1 次开方，GPU 上几乎零开销。

### 2.3 物理意义

| d_i 值 | 含义 | 粒子状态 |
|--------|------|----------|
| d_i → 0 | T ≈ I，近似刚体平移 | 几乎无扭曲 |
| d_i ∈ (0, 0.3] | 轻微剪切/拉伸 | 适度变形 |
| d_i > 0.3 | 显著扭曲/旋转 | 需要重分布 |

### 2.4 网格单元聚合

```
cell_deformation[cell] = (1/N_cell) · Σ d_i    (单元内粒子平均变形)
```

## 三、创新二：变形触发局部重分布

### 3.1 判定准则

```
cell_marked[cell] = ┌ 1,  if cell_deformation[cell] > θ_deform    (需要重分布)
                    └ 0,  otherwise                               (保持流图)
```

其中 `θ_deform = 0.3` 为变形阈值（可通过前几帧的 p90 分位数标定）。

### 3.2 局部重分布操作

仅对被标记的单元执行：

```
For each particle i in marked_cell:
    psi[i]    ← particles_pos[i]        (后向流图位置 = 当前位置)
    T_x[i]    ← [1, 0]^T                (流图重置为单位阵)
    T_y[i]    ← [0, 1]^T
    T_init[i] ← I                       (长距离映射重置)
    T_grad_m  ← I                       (短距离映射重置)
    重新从网格速度场采样冲量: imp = interp(u_grid, pos[i])
```

未被标记单元的粒子保持其累积流图不变 → **流场连续性得以保留**。

### 3.3 与原版的本质区别

```
原版 (全局):  每 20 步 → 100% 单元重置 → 所有流图丢弃 → 连续性断裂
优化版 (局部): 每 5 步检查 → 仅 10-30% 单元重置 → 平稳区流图继续累积
```

## 四、创新三：涡量引导自适应粒子密度

### 4.1 涡量计算（已有）

```
ω[i,j] = (dv/dx - du/dy) = (v_r - v_l - u_t + u_b) / (2·dx)

cell_vorticity[cell] = |ω|
```

### 4.2 密度分配

```
cell_density[cell] = ┌ HIGH (16/cell),  if |ω| > θ_vorticity    (涡旋核心)
                     └ LOW  (4/cell),   otherwise                (平稳区域)
```

其中 `θ_vorticity` = 涡量场的 75 分位数（自适应标定）。

### 4.3 粒子激活控制

```
particles_active[i] = ┌ 1,  if cell_density[cell(i)] == HIGH
                      │ 1,  if cell_density[cell(i)] == LOW AND local_idx < 4
                      └ 0,  otherwise
```

P2G 内核中仅活跃粒子参与动量传递：

```
P2G:  for i in particles:
          if particles_active[i] == 1:     ← 跳过非活跃粒子
              scatter momentum to grid
```

### 4.4 效果

- 涡旋核心：维持 16 粒子/单元的高精度采样
- 平稳区域：降至 4 粒子/单元，减少 75% 冗余
- 总体活跃粒子：通常 50-70%（取决于流场复杂度）

## 六、变形触发局部重分布详细流程

```
┌──────────────────────────────────────────────────┐
│        adaptive_local_reinit 内核                  │
└──────────────────────────────────────────────────┘
                      │
                      ▼
        ┌─────────────────────────┐
        │  for each particle i:    │
        │  cell_id = pos[i] / dx   │
        └───────────┬─────────────┘
                    │
                    ▼
        ┌─────────────────────────┐
        │  cell_marked[cell_id]   │
        │       == 1 ?            │
        └───────────┬─────────────┘
                    │
         ┌──────────┴──────────┐
         │ Yes (需要重分布)     │ No (保持流图)
         ▼                     ▼
┌─────────────────────┐   ┌──────────────┐
│ psi[i] = pos[i]     │   │  不做任何操作  │
│ T_x[i] = [1, 0]     │   │  流图保持累积  │
│ T_y[i] = [0, 1]     │   └──────────────┘
│ T_init[i] = I       │
│ T_grad_m[i] = I     │
│ imp[i] = interp(u)  │
└─────────────────────┘
```

**关键**：未被标记的粒子保留其累积的后向流图。这些粒子在平稳流场中可能存活数十甚至上百步而不重置 → 长距离无耗散传输的优势被最大化。

## 七、自适应密度详细流程

```
┌──────────────────────────────────────────────────┐
│      adaptive_density_redistribute 内核            │
└──────────────────────────────────────────────────┘
                      │
                      ▼
        ┌─────────────────────────┐
        │  for each particle i:    │
        │  cell_id = pos[i] / dx   │
        └───────────┬─────────────┘
                    │
                    ▼
        ┌─────────────────────────┐
        │  cell_density[cell_id]  │
        │       == HIGH ?         │
        └───────────┬─────────────┘
                    │
         ┌──────────┴──────────┐
         │ HIGH (涡旋核心)       │ LOW (平稳区域)
         ▼                      ▼
┌──────────────────┐   ┌──────────────────────┐
│ active[i] = 1    │   │ local_idx = i % 16   │
│ (全部 16 粒子激活)│   │                      │
└──────────────────┘   │ if local_idx < 4:    │
                       │   active[i] = 1      │
                       │ else:                │
                       │   active[i] = 0      │
                       │ (仅前 4 个粒子激活)   │
                       └──────────────────────┘
```

## 八、关键参数汇总

| 参数 | 值 | 说明 |
|------|-----|------|
| `deformation_threshold` | 0.3 | \|\|T-I\|\|_F 触发局部重分布阈值 |
| `vorticity_threshold_ratio` | 0.25 | 涡量阈值分位数（top 25% 为高密度区） |
| `adaptive_reinit_interval` | 5 | 每 N 步检查一次变形 |
| `adaptive_density_interval` | 10 | 每 N 步更新密度标记 |
| `particles_per_cell_high` | 16 | 涡旋核心区粒子密度 |
| `particles_per_cell_low` | 4 | 平稳区粒子密度 |
| `reinit_every_grad_m` | 8 | 短距离映射重置间隔（保持全局） |

## 九、理论优势总结

```
                    原版 PFM                    优化版 PFM
                    ────────                    ────────
重分布触发          固定步数 (j%20==0)           变形因子超阈值
重分布范围          100% 全局                    10-30% 局部
粒子密度            全局均匀 16/cell             自适应 4~16/cell
流图连续性          每 20 步强制断裂             平稳区流图可存活 >100 步
涡旋区域精度        与其他区域相同               保持高密度 16/cell
平稳区域效率        与涡旋区域相同               降至 4/cell (75% 节省)

评价指标改善:
  · 帧时间:      ↓ 25-40%    (粒子数减少 + 局部重分布跳过非活跃粒子)
  · 动能保持率:  ↑ 5-15 pp   (平稳区流图不被强制重置)
  · 涡量保持率:  ↑ 10-20 pp  (涡核高密度 + 及时局部重分布)
  · 有效分辨率:  ↑            (计算资源向高变形区集中)
```

## 十、新增 Taichi 内核清单

| 内核 | 功能 | 复杂度 |
|------|------|--------|
| `compute_particle_deformation` | 逐粒子计算 \|\|T-I\|\|_F | O(N_p) |
| `aggregate_cell_deformation` | 逐单元平均变形因子 | O(N_p) |
| `compute_cell_vorticity_mag` | 逐单元涡量幅值 | O(N_c) |
| `mark_cells_adaptive` | 标记需重分布和高密度单元 | O(N_c) |
| `count_marked_cells` | 统计标记单元数 | O(N_c) |
| `adaptive_local_reinit` | 局部流图重置 | O(N_marked) |
| `adaptive_density_redistribute` | 粒子激活/去激活 | O(N_p) |
| `count_active_particles` | 统计活跃粒子数 | O(N_p) |
| `compute_kinetic_energy` | 总动能 | O(N_c) |
| `compute_enstrophy` | 总拟能 | O(N_c) |
| `compute_deformation_stats` | 平均/最大变形因子 | O(N_c) |

> N_p: 粒子总数, N_c: 网格单元数, N_marked: 被标记单元内粒子数
